## บันทึกการแก้บั๊ก (กรอกครบทั้ง 6 จุด)

> แต่ละบั๊กเขียน 4 อย่าง: ไฟล์ · บรรทัด · สาเหตุ (ทำไมทำงานผิด) · แก้อย่างไร

### บั๊กที่ 1 — อาการ: Console เตือนสีเหลืองเรื่องรายการ
- **ไฟล์/บรรทัด:** `components/RequestList.jsx` (บรรทัดที่ 8)
- **สาเหตุ:** เมื่อไม่ได้ใส่ `key={...}` ให้กับ Element ตัวนอกสุดใน `.map()` React จะไม่สามารถระบุตัวตนของ Element แต่ละตัวได้อย่างแม่นยำ ส่งผลให้ขึ้น Warning เตือนใน Console
- **แก้อย่างไร:** แก้ไขโดยเพิ่ม attribute `key` ในบรรทัดที่ 8 ที่ Element ตัวนอกสุด: `<div key={request.id} className="request-item">`

---

### บั๊กที่ 2 — อาการ: ตัวเลข "รอดำเนินการ" ในแผงสรุปไม่ตรงกับที่เห็น
- **ไฟล์/บรรทัด:** `pages/DashboardPage.jsx` (บรรทัดที่ 47)
- **สาเหตุ:** ในบรรทัดที่ 47 มีการใช้ `.filter()` เช็ก `status === "completed"` ซ้ำกับบรรทัดที่ 49 จึงทำให้ตัวเลขแสดงจำนวนสถานะรอดำเนินการไม่ตรงกับข้อมูลจริง
- **แก้อย่างไร:** เปลี่ยนเงื่อนไขสถานะจาก `'completed'` เป็น `'pending'`:
  `pending: requests.filter((request) => request.status === 'pending').length`

---

### บั๊กที่ 3 — อาการ: กดตัวกรอง "รอดำเนินการ" แล้วได้รายการที่ไม่ใช่
- **ไฟล์/บรรทัด:** `pages/DashboardPage.jsx` (บรรทัดที่ 54)
- **สาเหตุ:** ในบรรทัดที่ 54 ใช้เปรียบเทียบด้วยเครื่องหมาย `!==` (ไม่เท่ากับ) ทำให้ตัวดักกรองส่งผลลัพธ์เป็นรายการที่ตรงข้ามกับสถานะที่ต้องการกรอง
- **แก้อย่างไร:** เปลี่ยนเครื่องหมายจาก `!==` เป็น `===` เพื่อให้กรองเฉพาะรายการที่ตรงกับสถานะรอดำเนินการ

---

### บั๊กที่ 4 — อาการ: เปลี่ยน URL จาก REQ-001 เป็น REQ-002 แล้วข้อมูลไม่เปลี่ยน
- **ไฟล์/บรรทัด:** `pages/RequestDetailPage.jsx` (บรรทัดที่ 28)
- **สาเหตุ:** ใน Dependency Array ของ `useEffect` ใส่เพียง `reloadKey` ทำให้เมื่อเปลี่ยน URL Parameter (`requestId`) ฟังก์ชันดึงข้อมูลจะไม่ทำงานซ้ำ ข้อมูลจึงค้างที่หน้าเดิม
- **แก้อย่างไร:** เพิ่ม `requestId` เข้าไปใน Dependency Array ของ `useEffect` เพื่อให้เกิดการดึงข้อมูลใหม่ตามตำแหน่ง ID ที่ค้นหา
