> แต่ละบั๊กให้เขียน 4 อย่าง: ไฟล์ · บรรทัด · สาเหตุ (ทำไมทำงานผิด) · แก้อย่างไร
> เขียนด้วยคำของตัวเอง — จุดนี้จะถูกถามใน oral

## บั๊กที่ 1 — อาการ: Console เตือนสีเหลืองเรื่องรายการ
- ไฟล์/บรรทัด: components/RequestList (บรรทัดที่ 8)
- สาเหตุ: สาเหตุที่ขึ้น Warning: เมื่อคุณไม่ได้ใส่ key={...} ให้กับ Element ตัวนอกสุดใน .map() Reactจะไม่สามารถระบุตัวตนของ Element แต่ละตัวได้อย่างแม่นยำ
- แก้อย่างไร: โดยแก้ไขโดยเพิ่ม Key ในบรรทัดที่ 8 เนื่องจากถ้าไม่มี key  ตัว  react จะไม่สามารถระบุตัวตนของ Element แต่ละตัวได้อย่างแม่นยำ `<div key={request.id} className="request-item">`
